Teste de colagem

Copie o mesmo trecho e cole em cada campo. Cada cartão mostra o que aquele caminho recebeu, para ver quais trazem nome e horário, se algum trouxer.

1. Caixa de texto

Campo comum de várias linhas. Só texto simples.

2. Campo de uma linha

Input simples. O navegador costuma juntar as linhas.

3. Área editável (rica)

Colagem nativa do navegador, que mantém a estrutura do HTML. Mostra o texto e o HTML resultante.

4. Evento de colagem

Clique na caixa e use Ctrl+V. Lista todos os formatos que o Teams ofereceu e o conteúdo de cada um.

5. Antes de inserir

O evento beforeinput numa área editável. Pode enxergar formatos que o caminho 4 não vê.

6. API da área de transferência

Lê a área de transferência por botão. O navegador pode pedir permissão.

7. Arrastar e soltar

Selecione o texto no Teams e arraste até aqui, sem copiar. Esse caminho não passa pelo Ctrl+C do Teams.
